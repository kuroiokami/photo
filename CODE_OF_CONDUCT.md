# Community conduct

Contributors and maintainers should make this a useful, respectful place to build photography software.

- Be considerate, specific and constructive. Discuss behavior, evidence and code without attacking people.
- Welcome different experience levels and accessibility needs.
- Respect privacy and ownership. Never post someone else's photographs, personal metadata or private communications without permission.
- Do not harass, discriminate, threaten, spam or make unwanted personal or sexual remarks.

These expectations apply to repository issues, pull requests, reviews and other project spaces. Maintainers may request edits, hide or remove content, close discussions, or restrict participation when necessary. Enforcement should be proportionate and consistent; maintainers follow the same expectations.

Use GitHub's **Report content** option for abuse. A non-sensitive project concern can be raised with the maintainer in the relevant discussion without repeating private information. Report vulnerabilities privately through [SECURITY.md](SECURITY.md). Do not post private allegations or sensitive evidence publicly to seek moderation.
